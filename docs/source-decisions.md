Embedded-license inspection left the downloaded raw archives unchanged. These decisions describe source acquisition and reuse evidence; normalization remains a later implementation step.

Access protocol: the downloader applies RFC 9309 wildcard and longest-match rules. An explicit `Disallow` is enforced. A 4xx response from `robots.txt` means that file is unavailable; it does not grant access to a protected dataset. Dataset-level 401/403, network failures and 5xx remain hard failures; 429/retry instructions are respected. GA's documented public MapServer API can be acquired under its stated license. MRDS's broad ArcGIS-host terms remain a separate access-review item.
